# Construction CRM

CRM-система для строительной компании на Next.js + Supabase.

## Модули
- Аутентификация и роли
- Проекты и этапы
- Склад
- Бухгалтерия
- Прорабы (заявки + фото)
- Транспорт (путевые листы)
- Воронка продаж (канбан)
- Интеграции: Telegram, MAX
- PWA для Android

## Запуск
\`\`\`bash
npm install
npm run dev
\`\`\`

## Переменные окружения
Создайте `.env.local` с ключами:
\`\`\`
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
\`\`\`
